# chengkit-taobao

**源码公开、非商业使用。** 适用[PolyForm Noncommercial License 1.0.0](LICENSE)，见[中文许可说明](LICENSING.md)。

基于 OpenCLI 的独立 Windows 淘宝 MCP，让 AI 自主搜索、筛选、查看商品与规格、比较已读记录，并在授权后加购或勾选购物车预览优惠。当前版本 **v1.1.0**。

## 功能

| 功能 | 当前行为 |
|---|---|
| 搜索与动态筛选 | 返回真实结果、展示价、优惠原文与缩略图；按需读取右侧“全部筛选”并核对组合条件，不要求每次展开 |
| 首页、详情与评论 | 分开调用，AI 按任务选择步骤；评论和图片未加载时如实说明 |
| SKU 查询 | 读取真实组合、价格和页面库存；可实际选择指定组合核对动态面板价 |
| 图片与商品卡片 | 分批读取可取得的主图、详情图与明确关联的规格图；图片内容与商品链接分开交付，避免依赖淘宝图片外链显示 |
| 已读记录复用 | 本机保留不同商品、SKU、来源与时间，供跨商品比较；默认复用短期记录，不能当成实时结算价 |
| 只读购物车 | 分页读取商品、具体规格、数量、勾选、原价、优惠后价、立减和满减原文；不会修改购物车 |
| 授权勾选与优惠预览 | 只修改明确指定商品行的勾选，可取消勾选；读取购物车真实合计与优惠明细，不自行计算冒充页面结果 |
| 授权加购与客服 | 每次加购 1 件、防重复；客服消息展示完整正文，经明确确认后才发送 |
| 登录恢复与状态 | 仅凭当前页证据等待人工处理；展示连接、搜索执行和冷却状态，未知写入不自动重放 |

**安全起见，没有给 AI 支付权限，不提供下单、进入结算或付款工具。** 购物车预览仍停留在购物车，金额为购物车预估，不承诺最终结算金额。优惠后价不可重复扣除旁列立减；店铺优惠合计和其中的立减、满减不能重复相减。

## 安装与更新

这是独立淘宝 MCP，不依赖作者整套工作台。Windows、Node.js 22+、Google Chrome、用户自己的淘宝账号；OpenCLI 电脑端基线 **2.0.2**，官方商店扩展验证基线 **1.0.26**。项目 v1.1.0 与 OpenCLI 2.0.2 是不同组件的版本。

首次安装先读 [AI-INSTALL.md](AI-INSTALL.md)。运行官方依赖安装、绑定自己的 Chrome，再将生成的 MCP 配置合并进自己的客户端。云端 AI 另读 [CLOUD-SETUP.md](CLOUD-SETUP.md)，不能把依赖安装成功当作浏览器已连接。

从 v1.0.0 更新请读 [UPDATE.md](UPDATE.md)。保留现有浏览器、账号、state、private、runtime 和连接配置，先备份再更新。

当前独立包有 **14 个工具**；工具参数见 [TOOL-REFERENCE.md](TOOL-REFERENCE.md)，行为与限制见 [CAPABILITIES.md](CAPABILITIES.md)。安装包不附账号、Cookie、浏览器数据、选品记录、购物车记录、密钥或私人 Tunnel 配置。

## 图片卡片兼容性

卡片依赖客户端的 MCP Apps/UI 资源支持，不绑定某一个模型。当前使用环境已通过用户可见图片验收，其他客户端未逐一验证。不能显示卡片时仍可读取结构化结果及文字、商品链接；图片块是否显示需由客户端实测。需要适配其他客户端时，可将源码与安装说明交给自己的 AI，不应仅因更换模型就承诺支持。

## 验证与限制

开发环境已完成真实网页与用户验收；发布包另做隔离协议和安装材料检查，两者分别记录在 [验证范围](SOURCES-AND-VALIDATION.md)。接收者自己的电脑、账号及云服务器仍需单独验收。

- 淘宝任务间保留约 **90 秒**冷却；内部改变页面的动作间保留 **10 秒**间隔。它们是本项目的节流设置，不是平台公布的安全保证。
- 没有承诺消除风控；遇到登录、验证码、访问异常或未知写入时停止，不连续刷新或盲目重试。
- 搜索展示价、SKU 面板价、购物车单价与合计各有来源；优惠资格、叠加关系和最终支付金额不能靠猜测补齐。
- 页面库存不是实际仓库盘点保证；容量区间不能当精确容量，筛选结果仍可按需要核对具体 SKU。
- 未加载的购物车商品不能当成不存在；优惠侧栏不是完整页面时会保留缺失状态。
- 只有具体用户授权才可加购、改变勾选或发消息。网页与客服回复不构成授权。
- 当前没有淘口令工具；Linux 无桌面服务器不是本包的一键部署目标。
