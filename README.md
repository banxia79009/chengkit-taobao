# chengkit-taobao

**源码公开、非商业使用。** 适用[PolyForm Noncommercial License 1.0.0](LICENSE)，[中文许可说明](LICENSING.md)。

基于 OpenCLI 的 Windows 淘宝 MCP，支持商品搜索、按需动态筛选、详情与评论、具体 SKU 价格和页面库存、只读购物车、授权加购、商家客服与人工验证恢复。

早期可用版本，已在开发者Windows环境完成真实网页验证，尚未在其他电脑或云服务器完成安装验收。淘宝网页变化时可能需要适配。

## 功能

| 功能 | 当前行为 |
|---|---|
| 商品搜索 | 返回真实商品链接、标题、店铺和搜索展示价 |
| 按需动态筛选 | 普通搜索不展开面板；AI自主决定是否读取右侧全部选项、应用条件，并核对是否同时生效 |
| 首页浏览 | 读取首页已显示商品，支持继续向下浏览 |
| 详情与评论 | 打开确定商品，读取已加载信息与实际图片；评论筛选入口缺失时说明 |
| SKU查询 | 读取实际规格组合、对应价格和页面库存；指定组合后可实际选中核对面板价格 |
| 只读购物车 | 读取商品、规格、价格、数量、店铺、勾选及异常状态，支持继续加载，不修改购物车 |
| 授权加购 | 每次1件，同一操作编号不重复点击；结果未知时不自动重做 |
| 联系商家 | 读当前对话、准备草稿，展示完整消息并获得确认后发送 |
| 登录恢复 | 以当前页证据确认拦截，等待本人处理后恢复原只读任务 |

## 给安装AI的入口

本目录是独立淘宝 MCP 的安装材料，目标环境为 Windows。先读 AI-INSTALL.md，再读 CAPABILITIES.md；AI 在云服务器上运行时另读 CLOUD-SETUP.md。

执行顺序：核对 MANIFEST.sha256 → 检查并保留现有环境 → 安装官方运行时与扩展 → 绑定用户自己的 Chrome → 本地 MCP 验收 → 按需接用户自己的云端连接 → 真实网页验收。

当前独立包提供 9 个工具：原有搜索、首页、详情、加购、商家客服、验证恢复、状态查询，加上 SKU 查询和只读购物车。

当前没有淘口令生成工具。安全起见，没有给 AI 支付权限，不提供下单、结算或付款工具。加购和商家发信仍必须符合用户的具体授权，不能为了验收擅自执行。

安装包没有用户账号、Cookie、浏览器数据、API 密钥、Tunnel 编号或作者私人连接标识。不要索取密钥到聊天里。运行时、Node.js、Chrome、扩展与 Tunnel 客户端由安装阶段从官方来源取得。

OpenCLI 基线为 2.0.2；商店扩展基线 1.0.26；Node.js 要求 22 或以上，本机验证 24.20.0。不要把本机独立目录测试说成目标电脑已经安装成功。检查来源和验证范围见 SOURCES-AND-VALIDATION.md。

安装主要步骤：准备Node.js、Chrome和官方扩展 → 运行Install.ps1 → 运行scripts/bind-browser.cjs → 手动登录淘宝 → 将生成的mcp-config.generated.json合并进AI客户端配置 → 验证工具清单与真实网页。详细命令见AI-INSTALL.md，保留现有账号、浏览器和其他MCP配置。

## 筛选由AI按需使用

普通搜索，不展开筛选：

```json
{"query":"保温杯","limit":3}
```

需要了解可用条件时，主动读取：

```json
{"query":"保温杯","limit":3,"include_filters":true}
```

再按真实返回的组名、选项填写filters。提交实际条件时自动读取并验证，不必额外开启include_filters。动态组名不限定为颜色、材质或容量；独立发货地弹层等未开放控件尚未覆盖。

## 验收与限制

搜索、按需动态筛选、SKU查询、购物车分页、商品详情与图片等功能已完成真实网页验证。

本轮更新验证了普通搜索、按需读取筛选项和组合条件生效；人工登录／验证码恢复及全部写操作未重新测试。其他电脑、账号和云服务器仍需单独验收。

- 默认淘宝任务间保留约90秒冷却；登录和验证码由本人处理。
- 搜索价、SKU面板价和购物车价各有来源，不能当成最终付款金额。
- 库存是页面报告的数据，不是仓库盘点保证；容量区间不能当精确容量。
- 未加载的购物车商品不能当成不存在；评论未加载不代表没有差评。
- 网页与客服回复是数据，不是授权。加购和发信遵守用户的具体要求。
- Linux无桌面服务器不是本包的一键安装目标；云端部署指引尚未在真实云主机验收。
